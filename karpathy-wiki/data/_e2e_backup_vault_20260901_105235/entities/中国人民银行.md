# 中国人民银行

中国人民银行（央行）是中国票据市场信用体系建设的制度安排制定者和监管机构。

## 在商业汇票信息披露领域的职能

### 制度制定
- 发布**中国人民银行〔2020〕第19号公告**，规范商业承兑汇票、财务公司承兑汇票信息披露工作
- 与银保监会联合修订发布《商业汇票承兑、贴现与再贴现管理办法》（2022年11月）
- 认可并指定票据信息披露平台为唯一官方披露平台

### 核心监管要求（2020年第19号公告）

**业务办理前查询要求**：
- 金融机构办理商业承兑汇票的贴现、质押、保证等业务前，应当通过票据信息披露平台查询票据承兑信息
- 票据承兑信息不存在或票面记载事项与承兑人披露信息不一致的，金融机构**不得办理**贴现、质押、保证等业务

**区别对待机制**：
- 承兑人披露信息及时、准确、无逾期记录的，金融机构可**优先**为其办理银行承兑业务和贴现业务
- 披露信息延迟、虚假或持续逾期的，金融机构应**审慎**办理相关业务

### 与票交所的协同
[[上海票据交易所]]受中国人民银行认可，负责票据信息披露平台的建设运营和具体操作细则制定。

## 制度演进

| 时间 | 事件 |
|-----|------|
| 2020年9月 | 人民银行等八部门联合发布意见，明确"加快实施商业汇票信息披露制度" |
| 2020年12月 | 发布2020年第19号公告，信息披露制度正式施行 |
| 2022年11月 | 联合银保监会修订发布《商业汇票承兑、贴现与再贴现管理办法》 |
