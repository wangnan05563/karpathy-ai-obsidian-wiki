# DFB001 银行账户查询申请报文

**报文 ID：DFB.001.001**

DFB001 是 [[中国票据业务系统直连接口规范（银行账户分册）]] 中定义的**银行账户查询申请报文**，由票交所系统向银行系统发起，用于查询指定银行账户的信息。
