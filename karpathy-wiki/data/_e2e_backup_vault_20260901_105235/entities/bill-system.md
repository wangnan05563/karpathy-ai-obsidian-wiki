# 票据业务系统

中国票据业务系统是支持[[huipiao-chengdui|汇票承兑]]与[[huipiao-tiexian|汇票贴现]]的银行对公业务核心模块。

## 核心功能

- **汇票承兑**：支持银行/商业汇票的承兑流程，确认付款义务。
- **汇票贴现**：支持持票人在票据到期前向银行申请贴现，提前获取资金。

## 业务定位

作为银行对公业务的核心模块，票据业务系统承接企业客户的票据签发、承兑、贴现、转贴现等一系列业务操作，是供应链金融与企业融资的重要基础设施。
