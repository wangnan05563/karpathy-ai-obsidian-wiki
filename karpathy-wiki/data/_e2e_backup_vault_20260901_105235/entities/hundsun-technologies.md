# 恒生电子

**恒生电子股份有限公司**（Hundsun Technologies Inc.）是一家中国金融科技公司，专注于为金融行业提供 IT 解决方案和服务。

## 相关规范

恒生电子制定了企业级的 [[恒生电子 Java 编码规范]]（Hundsun Java Coding Standard），为其全公司 Java 开发者提供规范化指导。该规范由 EPG 研发组编制，批准日期为 2023/03/15，涵盖了命名风格、常量定义、代码格式、OOP 规约、集合处理、并发处理、异常处理、日志规约等各方面的编码要求。
