# 恒生电子

恒生电子股份有限公司（Hundsun Technologies Inc.）是中国领先的金融科技公司，为银行、证券、基金、保险等金融机构提供 IT 解决方案。

## 票据交易管理平台 V5.0

恒生电子推出的 **票据交易管理平台 V5.0** 是一套面向票据业务的前端应用系统，包含完整的 Vue 前端组件体系。详见 [[恒生票据交易管理平台V5.0前端组件]]。

### 平台组件覆盖范围

- 文本框组件（通用文本框、批次号、票据号码、承兑人信息等）
- 下拉菜单与下拉框组件（票据介质、票据种类、业务类型、渠道等）
- 金额框与利率框组件
- 日期框组件（出票日期、汇票到期日等）
- 弹窗组件（票交机构、企业客户、通用树弹窗等）
- 表格与查询组件（Hdatagrid、查询按钮等）
