# HUI 前端技术框架

## 概述

**HUI** 是恒生电子股份有限公司（研发中心-HUI）研发的企业级前端技术框架，包含完整的技术框架及编码规范体系。HUI 旨在为 web 前端开发人员提供统一的开发规范，帮助团队更快、更好、更高效地完成复杂、多样化的前端开发任务。

## 核心目标

- **降低组员介入项目的门槛成本**
- **提高工作效率及协同开发的便捷性**
- **高度统一的代码风格**

## 环境要求

| 项目 | 要求 | 约束等级 |
| --- | --- | --- |
| Node.js | 10.15.3 版本 | 【强制】 |
| Python | 2.7.12 版本（兼容 install node-sass） | 【推荐】 |
| IDE | Visual Studio Code (VS Code) | 【强制】 |
| 格式化工具 | VS Code 内置格式化（Prettier） | 【强制】 |
| Vue 扩展 | Vetur 插件 | 【强制】 |
| 代码格式化 | Prettier - Code formatter | 【强制】 |
| Tab 大小 | 2 个空格 | 【强制】 |
| 行尾符 | LF（EditorConfig 插件） | 【推荐】 |
| 浏览器调试 | Chrome + Vue.js devtools | 【推荐】 |

## 约束等级体系

| 等级 | 说明 |
| --- | --- |
| **【强制】** | 违反将被认为代码存在严重缺陷，前端团队必须遵守 |
| **【推荐】** | 违反将被认为代码存在轻微缺陷，根据产品特性选择性遵守 |
| **【参考】** | 违反可被认为代码存在优化空间，供持续优化参考使用 |
