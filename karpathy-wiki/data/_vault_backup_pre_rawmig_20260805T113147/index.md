# 知识库目录

- [[llm-wiki]] — 基于大语言模型的 AI 自动编译知识库系统，由 Karpathy 提出
- [[harness]] — LLM Agent 运行时，提供工具调用循环、状态管理、重试、预算控制

- [[vector-database]] — 向量数据库——专门存储和检索向量嵌入的数据库，RAG 系统的核心基础设施。
- [[Mixture of Experts]] — 一种稀疏激活的神经网络架构，通过路由器动态分配输入给专家子模型，在提升容量的同时控制推理成本。
