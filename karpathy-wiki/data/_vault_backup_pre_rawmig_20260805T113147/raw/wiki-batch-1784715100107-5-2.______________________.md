## **业务办理渠道信息通知报文(MEM.001.002)**

### **报文功能**

当场务创建或修改业务办理渠道信息，且相关信息需要广播时，票交所向所有直连业务办理渠道发送被修改业务办理渠道的相关信息。

### **报文结构**

| **序号** | **报文要素** | **<XML Tag>** | **属性** | **类型** | **备注** |

|  | --变更类型 | <AltrnTp/> | [1..1] | AltrnTp |  |
|  | --变更时间 | <AltrnTm/> | [1..1] | ISODateTime |  |
|  | --业务办理渠道代码 | <MbrId/> | [1..1] | MaxMin6NumericText |  |
|  | --业务办理渠道类别代码 | <MbrTp/> | [1..1] | MemberType | 银行  非银  资管  存托  供应链平台  B2B平台 |

### **报文说明**

财务公司ECDS线上清算权限为是的机构参与者，可以通过票据业务系统资金账户实现ECDS系统中的托收追索等业务的线上清算。

### **报文处理规则**

1.参与者收到“业务办理渠道信息通知报文”后，按报文规范解析报文，获取相应的信息，更新自身系统中相应的业务办理渠道信息。

2.清算模式为模式二的业务办理渠道信息发生变更时下发MEM001报文，ECDS线上清算权限为“无”或“有”，均下发该字段；除清算模式二以外，其他机构均不下发该字段。

①维护子类操作类型为“修改”，维护子类为“客户信息”、“客户属性信息”、“客户信用信息”、“附件信息集合”、“法定代表人信息”时，对应维护子类节点信息覆盖。

②维护子类操作类型为“修改”，维护子类为“结算账户信息”时，可以根据账户操作类型进行结算账户信息的新增、修改和删除。修改客户结算账户信息时，账号与开户行号作为唯一主键，不允许修改，其他结算账户信息字段可修改。

③维护子类操作类型为“删除”，维护子类可为“客户信用信息”、“结算账户信息”、“客户属性信息”或“法定代表人信息”，客户信息节点必填，其他节点不填写。维护子类为“结算账户信息”时，删除该客户在该业务办理渠道下报备的所有账户。维护子类可为“客户属性信息”或“法定代表人信息”时；删除对应节点信息。

（4）任何维护操作中，客户信息为必填项，客户信息中的“统一社会信用代码”不支持修改。

3.客户结算账户信息控制规则：

（1）单个报文内只能有一种结算账户操作类型。

（2）对于报备业务办理渠道为金融机构参与者时，结算账户开户行应与业务办理渠道为同一法人。

（3）对于业务办理渠道为金融机构的企业，其银行结算账户信息删除或更改的规则如下：

①删除银行结算账户信息时，

A.该账户作为承兑人、持票人(含质权人）、出质人、（回购式贴现）贴现申请人角色下不存在存量未结清的票据；其中作为出质人和质权人角色的，仅包括质押期间的票据，若质押票据已解质押，作为曾经的出质人和质权人，不在检查范围内；作为（回购式贴现）贴现申请人角色的，仅包括回购式贴现期间的票据，若票据已赎回或已逾期（归贴现行所有），作为曾经的（回购式贴现）贴现申请人，不在检查范围内。

B.该账户作为被追索人时，存在追索同意清偿申请待应答的业务，不能被删除。

（4）对于业务办理渠道为供应链平台的企业，其银行结算账户信息删除或更改的规则如下：

①删除银行结算账户信息时，检查非备用清算路径账户不是该业务办理渠道下删除的最后一个结算账户，备用清算路径账户必须是该业务办理渠道下删除的最后一个结算账户。

A.若删除非备用清算路径账户时，系统应检查：

a.该账户作为资金清算账户时，不存在DVP业务模式下作为贴现（申请人）、回购式贴现赎回（应答人）、提示付款（双方）的待应答或待清算业务（包括资金扣款确认、延时清算）。

b.该平台下企业作为被追索人时，存在FOP模式下追索同意清偿申请待应答的业务，不能被删除。

B若删除备用清算路径账户时，系统应检查：

a.该账户作为承兑人、持票人(含质权人）、出质人、（回购式贴现）贴现申请人角色下不存在存量未结清的票据；其中作为出质人和质权人角色的，仅包括质押期间的票据，若质押票据已解质押，作为曾经的出质人和质权人，不在检查范围内；作为（回购式贴现）贴现申请人角色的，仅包括回购式贴现期间的票据，若票据已赎回或已逾期（归贴现行所有），作为曾经的（回购式贴现）贴现申请人，不在检查范围内。

b.该账户作为资金清算账户时，不存在DVP业务模式下作为贴现（申请人）、回购式贴现赎回（应答人）、提示付款（双方）的待应答或待清算业务（包括资金扣款确认、延时清算）。

c.该平台下企业作为被追索人时，存在FOP模式下追索同意清偿申请待应答的业务，不能被删除。

d.该平台下企业作为信托转出应答人时，存在FOP模式下信托转出待应答的业务，不能被删除。

②变更备用清算路径账户时：

**A.若原备用清算路径账户的开户机构已被承接，**可直接变更备用清算路径账户。

**B.若原备用清算路径账户的开户机构未被承接，**系统应检查：

a.该账户作为资金清算账户时，不存在DVP业务模式下作为贴现（申请人）、回购式贴现赎回（应答人）、提示付款（双方）的待应答或待清算业务（包括资金扣款确认、延时清算）。

b.该平台下企业作为被追索人时，存在FOP模式下追索同意清偿申请待应答的业务，不能被删除。

（5）客户信息注销时，系统校验该客户在该业务办理渠道下的所有结算账户应已全部删除。

4.供应链平台新增客户信息后，票据业务系统为该企业自动分配票据账户账号并通过通用确认报文返回。

### **报文说明**

1. 账户限制权限清单字段受限权限允许填写：

CG00 – 不限制权限

权限清单（多个） – 各受限权限以“|”分割。

### **报文处理规则**

* + - 1. 该报文仅限主办账户所在业务办理渠道发起，申报机构应与主办账户开户机构为同一业务办理渠道。
      2. 账户权限信息维护后，立即生效。
      3. 待维护权限账户必须已经开通主动账户管理功能，账户必须为已登记的账户。
      4. 受限权限清单字段，如果出现CG00不允许出现其它受限权限；如果多个受限权限则以|分割。
      5. 申报机构代码须为主办账户申报机构或其上级机构。
      6. 账户权限维护后新权限生效，该账户原权限失效，“覆盖”逻辑。

## **主动管理通知报文（PAM.004.001）**

### **报文功能**

1. 变更主办账户成功后，票交所向新的主办账户申报机构下发该通知报文，反馈该客户已登记的账户明细、账户权限明细。

2. 添加普通账户至主动账户管理名单、从主动账户管理名单移除普通账户、修改名单中普通账户的受限权限时，向普通账户开户机构下发此报文。

### **报文说明**

1.变更主办账户成功后，通知报文中包含有效的主办账户、普通账户信息。

2.从主动账户管理名单移除普通账户时，通知报文中账户受限权限清单为空，账户状态为无效。

3.当添加普通账户至主动账户管理名单，通知报文中账户受限权限清单为CG00，账户状态为有效。

4.修改名单中普通账户的受限权限时，账户状态为有效。

5.登记生成日期、登记人、登记金融机构代码为账户首次添加至主动管理名单时对应登记信息。
