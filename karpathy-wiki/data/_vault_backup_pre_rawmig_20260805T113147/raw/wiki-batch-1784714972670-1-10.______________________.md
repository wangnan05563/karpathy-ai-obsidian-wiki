## **票据服务费信息通知报文（CHS.001.002)**

### **报文功能**

1.每个计费周期结束后票交所计算各会员票据服务费用后，基于计费信息发送本报文给会员单位，作为收费通知。

### **报文结构**

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| **序号** | **报文要素** | **<XML Tag>** | **属性** | **类型** | **备注** |

### **报文说明**

1.服务费期数：账单计费周期时间。例如：201901

2.计费开始时间：账单周期的第一个计费日。

3.计费终止时间：账单周期的最后一个计费日。

4.计费信息：资管/存托类会员接收到的报文包含多个产品的计费信息。调整账单后，资管/存托类会员接收到报文仅包含调整后的产品计费信息。

5.机构参与者代码：银行或非银类会员，展示法人机构参与者代码；资管/存托类会员，展示各产品机构参与者代码。

6.计费总额：交易手续费+结算过户费+账户维护费+其他结算费+其他费用。

7.优惠金额：满足优惠条件后，计算的优惠金额。

8.违约金：根据违约金规则，对逾期缴纳的账单计收的违约金。

9.应缴金额：计费金额-优惠金额+违约金。

### **报文处理规则**

1.票交所调整会员已出账单后，会将最新的服务费信息通知报文发送给业务办理渠道。

2.针对产品，票交所将以扣费机构参与者为单位单独下发服务费信息报文。（一个产品一个服务费信息通知报文）

3.若票交所调整费用，交易手续费、结算过户费、账户维护费、其他结算费、终端使用费、其他费用可能出现负数，但计费总额不能为负数。

## **票据服务费扣收结果通知报文（CHS.002.002)**

### **报文功能**

票据服务费结算完成后，通知会员业务扣费结果

### **报文结构**

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| **序号** | **报文要素** | **<XML Tag>** | **属性** | **类型** | **备注** |
|  | 报文标识 | <MsgId/> | [1..1] |  |  |
|  | --报文标识号 | <Id/> | [1..1] | Max35NumericText |  |
|  | --报文时间 | <CreDtTm/> | [1..1] | ISODateTime |  |
|  | 账单信息 | <FeeInf/> | [1..1] |  |  |
|  | --服务费期数 | <ChrgMnth/> | [1..1] | Max8NumericText | 示例：201901 |
|  | --扣费日期 | <ChrgDt/> | [1..1] | ISODate | 2019-02-15 |
|  | --应缴金额 | <TolFeeAmt/> | [1..1] | CurrencyAndAmount |  |
|  | --付款方机构参与者代码 | <Dbtr/> | [1..1] | MaxMin9NumericText |  |
|  | --大额支付系统报文标识号 | <CcpcMsgId/> | [0..1] | Max35NumericText |  |
|  | --扣费结果 | <ChrgFlag/> | [1..1] | ChrgFlag |  |
|  | 扩展属性信息 | <ExtInfs/> | [0..1] | 【扩展属性信息组件】 |  |
|  | --扩展属性 | <ExtInf/> | [1..n] |  |  |
|  | ----属性名 | <Name/> | [1..1] | Max150Text |  |
|  | ----属性值 | <Value/> | [1..1] | UnType |  |

### **报文说明**

1.服务费期数：账单周期时间。例如：201901

2.扣费日期：票交所进行扣费时的操作日期。

3.应缴金额：计费金额-优惠金额+违约金。

4.付款方机构参与者代码：银行或非银类会员，付款方为法人机构参与者代码；资管/存托类会员，按产品依次扣收，付款方为产品机构参与者代码。

5.支付系统报文标识号：对于业务请求的付款方需通过人民银行大额支付系统进行清算的结算请求，同时返回大额支付系统的报文标识号；若业务请求仅在票交所内进行内部资金账户清算的请求，则为空。

6.扣费结果为清算成功，清算失败。

### **报文处理规则**

1.当期费用账单为0，则不下发服务费扣收结果通知报文。
