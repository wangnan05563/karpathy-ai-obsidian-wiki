# 恒生电子

**恒生电子股份有限公司**（Hundsun Technologies Inc.）是一家以金融科技为核心的上市公司，为银行、证券、保险等金融机构提供IT解决方案。

## 电子商业汇票产品

恒生电子为商业银行提供[[电子商业汇票综合处理平台]]（BBSP），版本号 V5.0 / V450，由银行第五产品事业部负责开发，编制人为杨军。

该平台涵盖以下业务种类：
- 电子票据
- 实物票据
- 票据代理
- 票据池
