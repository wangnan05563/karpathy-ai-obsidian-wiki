## 概述

CPP014002 是票交所的挂牌询价 API 接口。用于在市场中进行挂牌询价操作。

## 相关规则

- 携带 FT07 其他类型的附件时，在[[综服平台]]中可以不用通过 [[CPP001002]] 绑定
- 但在[[交易系统]]中仍然需要通过 CPP001002 绑定后才能携带出去
