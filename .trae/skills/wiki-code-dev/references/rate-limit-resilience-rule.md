# 限流韧性规则（真实 IP / 滑动窗口 / 时钟无关测试）

**代码**：CODING-RATE-LIMIT-RESILIENCE
**严重级别**：high

## 问题（Problem）

固定窗口的认证限流器跨越了 60 秒"真实分钟"边界，导致完整测试套件中出现**偶发**的 429/200 抖动；按 IP 的桶在代理后**塌缩**（`request.ip === 127.0.0.1`，所有请求被视为同一客户端）。

## 规则（Rule）

### R-1：通过 `X-Forwarded-For` 还原真实客户端 IP
从 `X-Forwarded-For` 取真实客户端 IP；**保持 `trustProxy: false`** 避免请求头伪造导致的信任绕过。不要直接信任 `request.ip`（代理后恒为 127.0.0.1）。

### R-2：使用滑动/有界窗口 + 周期性清理
使用滑动窗口或固定窗口 + sweep，并**定期清理**计数 Map，避免 Map 无界增长（内存泄漏 + 桶塌缩）。

### R-3：验证使用恒定时间比较
认证相关的验证（如令牌/签名比对）使用恒定时间比较，避免时序侧信道。

### R-4：测试不得依赖真实时钟分钟边界
限流测试必须用 fake timers / 注入时钟，**不能**依赖墙上时钟的分钟边界，否则会在整分钟切换时 flaky。

## 适用 / 不适用

- **适用**：认证中间件、限流、代理后部署、限流相关单元测试。
- **不适用**：无认证/无 IP 维度的纯内部调用、静态资源服务。

## 检查清单
- [ ] 真实 IP 是否从 `X-Forwarded-For` 取且 `trustProxy:false`
- [ ] 限流窗口是否滑动/有界且会 sweep 清理
- [ ] 认证验证是否恒定时间
- [ ] 限流测试是否用假时钟（不依赖真实分钟边界）
