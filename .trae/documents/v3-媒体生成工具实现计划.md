# v3 媒体生成工具实现计划

## Summary

实现 Query.vue 工具栏中标记为"v3 待实现"的三个工具：**PPT 生成**、**图像生成**、**视频生成**。采用混合架构：图像/PPT 走 query SSE 流（与 multimodal 输出一致），视频走独立 JSON 端点（参考 podcast 模式，避免 60 秒 SSE 超时）。生成的媒体文件下载归档到 vault `queries/` 目录（与 podcast 一致）。使用 Agnes Image 2.1 Flash API 和 Agnes Video 2.0 API，PPT 通过 LLM 生成 Marp Markdown 并用 `@marp-team/marp-core` 渲染。

### Agnes API 细节（来自官方文档）
- **Image API**: `POST https://apihub.agnes-ai.com/v1/images/generations`
  - 模型: `agnes-image-2.1-flash`，价格 $0/张
  - 参数: `model`, `prompt`, `size`（1K/2K/3K/4K 或 1024x768）, `ratio`（1:1/3:4/16:9 等）, `return_base64`(boolean)
  - 响应: `data[].url` 或 `data[].b64_json`
- **Video API**: 异步任务，价格 $0/秒
  - 创建: `POST /v1/videos`，返回 `task_id`/`video_id`/`status`/`progress`
  - 轮询: `GET /agnesapi?video_id=<VIDEO_ID>`（推荐）或 `GET /v1/videos/<TASK_ID>`（兼容）
  - 模型: `agnes-video-v2.0`，参数: `model`, `prompt`, `size`（1280x720）, `seconds`, `num_frames`, `frame_rate`
  - 状态: `queued` → `processing` → `completed`/`failed`，完成后响应含 `url`

## Assumptions & Decisions

1. **架构决策**：混合模式
   - 图像/PPT 走 query SSE 流（与 multimodal 一致，在 done 前推送 image/ppt 事件，60 秒内可完成）
   - 视频走独立 JSON 端点（参考 podcast 模式，前端轮询任务状态，避免 SSE 超时）
2. **存储决策**：下载归档到 vault `queries/` 目录
   - 图像：下载到 `queries/image-{timestamp}.png`，归档 `queries/image-{timestamp}.md`
   - 视频：下载到 `queries/video-{timestamp}.mp4`，归档 `queries/video-{timestamp}.md`
   - PPT：Marp Markdown 直接归档到 `queries/ppt-{timestamp}.md`（无媒体文件）
3. **PPT 渲染**：引入 `@marp-team/marp-core` 库，前端动态加载渲染 Marp Markdown 为 HTML 幻灯片
4. **配置决策**：新增 `media` 配置段管理 Agnes API 参数，复用 `llm.apiKeys.agnes` 密钥
5. **模式映射**：工具栏 `image`/`ppt` 模式映射到 `outputMode='image'/'ppt'`，复用现有 outputMode 透传机制
6. **视频工具触发**：点击"视频生成"工具打开独立对话框（不走 sendQuestion），输入 prompt 后调用 `/api/media/video` 创建任务

#### 2.3 新增 [api/src/workflows/media-generation-workflow.ts](file:///d:/code/otherProjects/19_Karpathy-AI+Obsidian知识库/karpathy-wiki/api/src/workflows/media-generation-workflow.ts)
- `generateImage(harnessConfig, vault, question, contextPaths, mediaConfig)`:
  1. 复用 `collectContextPages` 收集上下文（从 multimodal-output-workflow 提取为共享函数）
  2. 调用 LLM 生成优化的图像 prompt（英文）
  3. 调用 Agnes Image API `POST /v1/images/generations`
  4. 下载图片到 `queries/image-{timestamp}.png`
  5. 归档到 `queries/image-{timestamp}.md`（frontmatter type: query, output_mode: image）
  6. 返回 `{ url: '/api/files?path=queries/image-xxx.png', alt: question, archivePath }`
- `generatePpt(harnessConfig, vault, question, contextPaths)`:
  1. 复用 `collectContextPages` 收集上下文
  2. 加载 `ppt-generation.md` prompt 模板
  3. 调用 LLM 生成 Marp Markdown（单轮，maxSteps:1, tokenBudget:16000）
  4. 归档到 `queries/ppt-{timestamp}.md`（frontmatter type: query, output_mode: ppt）
  5. 返回 `{ markdown, title: question.slice(0, 30), archivePath }`
- `generateVideo(harnessConfig, vault, prompt, mediaConfig)`:
  1. 调用 Agnes Video API `POST /v1/videos` 创建任务
  2. 返回 `taskId`/`videoId`（不阻塞，前端轮询）
- `pollVideoTask(taskId, vault, mediaConfig)`:
  1. 调用 `GET /agnesapi?video_id=<VIDEO_ID>` 查询状态
  2. 完成时下载视频到 `queries/video-{timestamp}.mp4`
  3. 归档到 `queries/video-{timestamp}.md`
  4. 返回 `VideoTaskResult`
- **超时与重试**：Image API 60 秒超时；Video 创建任务 30 秒超时；Video 轮询单次 10 秒超时，前端控制轮询间隔
- **错误处理**：Agnes API 失败时抛错让上层 catch，SSE 流中 yield thinking 提示失败原因

## 风险与缓解

1. **Agnes API 限流**：1 req/min（视频），需在前端轮询间隔 ≥ 5 秒，后端限流 5/min
2. **视频生成时间长**：最长 10 分钟，前端轮询需支持取消，对话框关闭时停止轮询
3. **Marp 库体积**：~200KB，动态加载避免首屏影响
4. **config.json 兼容**：`media` 字段可选，老配置无此字段时降级提示"未配置 Agnes API Key"
5. **.vue.js 编译产物污染**：修改 .vue 文件后需清理对应 .vue.js（project memory 已记录此问题）
